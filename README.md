# Simple Quiz Game

Open `index.html` in a browser to play the 5-question quiz. The game shows a final result: "You win!" if you score at least 3 out of 5, otherwise "You lose!".

Files created:

- `index.html` — main page
- `style.css` — styling
- `script.js` — quiz logic

To open on macOS from the project folder:

```bash
open index.html
```
